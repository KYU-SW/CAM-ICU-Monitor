**AI 보조 기반 디지털 섬망 평가 및 환자 모니터링 시스템**

`Python` `Flask` `SQLite` `LLM API` `Google Colab` `Version 11`

## 📌 1. 프로젝트 소개

**KY CAM-ICU/RASS**는 중환자실 환자의 의식 및 진정 수준과 섬망 상태를 체계적으로 평가하고, 평가 결과를 디지털로 기록·관리하는 웹 기반 시스템입니다.

의료진의 평가 과정을 디지털화하여 환자별 기록을 체계적으로 관리하고, 반복적인 평가 업무와 환자 상태 확인을 효율적으로 수행할 수 있도록 개발하였습니다.

특히 간호사가 작성한 환자 관찰 서술을 AI가 RASS 공식 정의에 따라 해석하여 참고 점수와 판단 근거를 제시하며, 최종 RASS 점수는 간호사가 직접 확인하고 확정하도록 설계하였습니다.

확정된 RASS 점수와 CAM-ICU 평가 결과를 바탕으로 환자의 섬망 상태를 판정하고, 환자별 평가 기록, 상태 변화, 재평가 일정, 근무 인계 정보 및 병동별 통계를 통합적으로 관리합니다.

### 주요 목표

- RASS 및 CAM-ICU 평가 과정의 디지털화
- LLM 기반 환자 관찰 서술 해석 및 참고용 RASS 점수 제안
- 의료진의 최종 평가 권한 보장
- CAM-ICU 판정 공식의 일관된 적용
- 환자별 평가 기록 및 상태 변화 모니터링
- 재평가 일정 관리 및 근무 인계 지원
- 사용자 권한에 따른 환자 정보 접근 관리
- 평가 데이터의 통계 분석 및 시각화

## 🧠 2. 핵심 평가 도구

### RASS (Richmond Agitation-Sedation Scale)

환자의 각성 및 진정 수준을 **-5점부터 +4점까지** 평가하는 도구입니다.

| 점수 | 상태 |
|---|---|
| +4 | 폭력적 |
| +3 | 매우 흥분 |
| +2 | 흥분 |
| +1 | 불안 |
| 0 | 깨어 있고 차분함 |
| -1 | 졸림 |
| -2 | 가벼운 진정 |
| -3 | 중등도 진정 |
| -4 | 깊은 진정 |
| -5 | 각성 불가 |

> Sessler CN et al. *Am J Respir Crit Care Med.* 2002;166:1338–1344.

### CAM-ICU (Confusion Assessment Method for the ICU)

중환자실 환자의 섬망을 평가하는 도구로, 다음 네 가지 특징을 확인합니다.

| 항목 | 평가 내용 |
|---|---|
| F1 | 급성 정신 상태 변화 또는 변동 경과 |
| F2 | 주의력 장애 |
| F3 | 의식 수준 변화 |
| F4 | 비체계적 사고 |

> Ely EW et al. *JAMA.* 2001;286(21):2703–2710.

### CAM-ICU 양성 판정 공식

```text
POSITIVE = F1 AND F2 AND (F3 OR F4)
```

F1과 F2가 모두 충족되고, F3 또는 F4 중 하나 이상이 충족되면 CAM-ICU 양성으로 판정합니다.

판정 공식은 서버에서 자동 계산하며, 사용자가 결과를 임의로 지정할 수 없도록 구성하였습니다.

## ⚙️ 3. 주요 기능

### 🔐 사용자 인증 및 권한 관리

- 간호사 및 관리자 통합 KY 로그인

### 👩‍⚕️ 관리자 페이지

관리자는 간호사 계정과 환자 정보를 통합적으로 관리할 수 있습니다.

**간호사 관리**
- 간호사 목록 조회
- 이름, 아이디, 사번, 병동, 담당 환자 수 및 등록일 확인
- 간호사 계정 등록
- 계정 삭제 시 해당 간호사의 아이디와 비밀번호를 입력하는 이중 확인 절차

**환자 관리**
- 병동별 환자 목록 구분 (전체 / 중환자실 A / 중환자실 B)
- 환자 이름, 코드, 병실 통합 검색
- 50명 단위 페이지네이션
- 환자 등록, 수정 및 삭제
- 환자 이름, 병실, 나이, 성별, 병동, 상태, 진단명, 입원일, 진정제 사용 여부 수정
- 담당 간호사 배정 및 변경

### 📋 담당 환자 대시보드

간호사는 로그인 후 자신이 담당하는 환자 목록을 확인할 수 있습니다.

**주요 기능**
- 담당 환자 목록 조회
- 환자 이름 및 병실 실시간 검색
- 병원명, 사번, 병동, 간호사 이름 표시
- 환자 입원 상태 확인
- 최근 CAM-ICU 평가 결과 표시
- 재평가 필요 환자 확인

**5가지 정렬 기능**
1. 병실 순
2. 위험 순
3. 재평가 필요 순
4. 이름 순
5. 최근 검사 순

**재평가 카운트다운**

| 최근 평가 결과 | 재평가 안내 |
|---|---|
| POSITIVE | 4시간 이내 |
| NEGATIVE | 8시간 |
| UNASSESSABLE | 진정 수준 등 환자 상태 변화 시 |
| 미평가 | 첫 평가 필요 |

재평가 카운트다운은 30초마다 갱신되며, 재평가 시간이 임박하거나 경과한 경우 시각적으로 강조합니다.

> 재평가 간격은 교육·시연용으로 설정된 기준이며, 실제 임상 적용 시 의료기관의 프로토콜을 따라야 합니다.

### 📝 6단계 디지털 평가

간호사의 환자 관찰과 최종 판단을 중심으로 RASS 및 CAM-ICU 평가를 진행합니다.

**STEP 1. 관찰 서술 및 AI 해석**

간호사가 환자의 상태를 관찰한 내용을 자연어 문장으로 입력합니다.

AI는 입력된 서술을 RASS 공식 정의와 비교하여 다음 정보를 제안합니다.

- 참고 RASS 점수
- 해당 RASS 평가 기준
- 입력된 관찰 서술에서 인용한 판단 근거

근거가 원문에 존재하지 않거나 충분하지 않으면 판단을 보류합니다.

관찰 서술 입력 영역에는 개인정보 입력 금지 안내를 표시합니다.

**STEP 2. 표준 절차 관찰**

환자의 반응을 다음 순서에 따라 단계적으로 확인합니다.

1. 무자극 상태 관찰
2. 음성 자극에 대한 반응 관찰
3. 신체 자극에 대한 반응 관찰

각 단계에서 환자의 반응에 해당하는 항목을 선택합니다.

**STEP 3. 간호사 최종 RASS 확정**

표준 절차 관찰 결과를 바탕으로 최종 RASS 입력란이 자동으로 채워집니다.

간호사는 해당 점수를 확인하고 필요한 경우 직접 수정하여 최종 RASS를 확정합니다.

AI 제안 점수와 간호사의 확정 점수가 다르면 경고가 표시됩니다.

AI 참고 점수는 최종 RASS에 자동 적용되지 않습니다.

**STEP 4. CAM-ICU 특징 평가**

CAM-ICU의 F1, F2, F4 항목을 평가합니다.

F3는 확정된 RASS 점수를 기준으로 자동 계산하며, RASS가 0이 아닌 경우 양성으로 처리합니다.

최종 RASS가 -4 또는 -5인 경우 CAM-ICU 평가를 진행하지 않고 `UNASSESSABLE`로 처리합니다.

**STEP 5. 평가 메모 작성**

진정제 용량 변경이나 특이 관찰 사항 등 필요한 내용을 선택적으로 기록합니다.

AI 해석 기능을 실행하더라도 기존에 입력한 관찰 서술과 메모가 유지되도록 구성하였습니다.

**STEP 6. 평가 저장**

서버에서 CAM-ICU 판정 결과를 계산하고 평가 기록을 데이터베이스에 저장합니다.

### 🤖 LLM 기반 AI RASS 참고 기능

간호사가 작성한 관찰 서술을 LLM이 해석하여 RASS 평가를 보조합니다.

**주요 특징**
- 자연어 관찰 서술 분석
- RASS 공식 정의에 따른 참고 점수 제안
- 입력 원문에 근거한 판단 문장 인용
- 원문에 존재하지 않는 인용을 사용한 결과 차단
- 근거가 부족한 경우 판단 보류
- AI 제안과 간호사 최종 점수의 차이 표시
- AI 기능을 사용할 수 없는 경우에도 기본 평가 진행 가능

**AI 결과 상태**

| 상태 | 의미 |
|---|---|
| SCORED | AI가 참고 RASS 점수를 제안 |
| ABSTAIN | 근거 부족 등으로 판단 보류 |
| UNAVAILABLE | AI 서비스를 사용할 수 없음 |
| NOT_RUN | AI 평가를 실행하지 않음 |

가상으로 생성된 평가 기록은 AI 분석을 실제 수행한 기록이 아니므로 `NOT_RUN`으로 구분합니다.

> AI 결과는 참고용 보조 정보이며, 최종 평가 권한은 의료진에게 있습니다.

### 🚦 RASS 게이트

```text
최종 RASS >= -3
    → CAM-ICU 평가 진행
    → F1, F2, F4 평가
    → F3 자동 계산
    → POSITIVE / NEGATIVE 판정

최종 RASS = -4 또는 -5
    → CAM-ICU 평가 불가
    → UNASSESSABLE 처리
```

CAM-ICU 판정은 서버에서 처리하며, RASS -4 또는 -5인 환자가 일반적인 음성 결과로 처리되지 않도록 평가 절차를 제한합니다.

| 사용자 | 접근 범위 |

> 위 수치는 기존 v6의 시뮬레이션 생성 기준입니다. v11 데이터베이스에 동일한 생성 파라미터가 적용되는지는 별도 확인이 필요합니다.

**API 키와 비밀 설정값은 GitHub 저장소에 업로드하지 않습니다.**

## 📄 11. 프로젝트 버전

### KY CAM-ICU/RASS v11

**AI 보조 기반 디지털 섬망 평가 및 환자 모니터링 시스템**

v11은 기존 디지털 RASS 및 CAM-ICU 평가 시스템을 기반으로, LLM을 활용한 관찰 서술 해석 기능과 간호사의 평가 업무를 지원하는 기능을 강화한 버전입니다.

### 주요 개선 사항

**1. AI 기반 RASS 참고 기능**
- 자연어 관찰 서술 해석
- RASS 공식 정의에 따른 참고 점수 제안
- 원문 인용 근거 검증
- 근거 부족 시 판단 보류
- AI 제안과 간호사 최종 점수 차이 표시

**2. 디지털 평가 절차 개선**
- 단계별 표준 절차 관찰
- 표준 관찰 결과에 따른 RASS 자동 입력
- 간호사 최종 RASS 확인 및 수정
- CAM-ICU F3 자동 계산
- RASS -4/-5 평가 게이트 적용

**3. 근무 인계 지원**
- 재평가 마감 초과 환자 표시
- CAM-ICU POSITIVE 전환 및 해제 표시
- RASS 2점 이상 변화 표시
- 미평가 환자 확인

**4. 통계 접근 권한 강화**
- 간호사 소속 병동 통계만 조회
- 관리자 전체 병동 통계 조회
- 담당 환자 여부에 따른 환자 이름 표시 제한

**5. AI 평가 및 기록 관리**
- AI 정확도 평가 스크립트 추가
- 기존 키워드 방식과 비교 평가 지원
- 가상 평가 기록의 AI 실행 상태를 `NOT_RUN`으로 구분
